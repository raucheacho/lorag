De tes fichiers à tes agents.From your files to your agents.

02 · mémoirememory

Rappeler, garder, noter.Recall, keep, rate.

Tes agents reçoivent ces règles à la connexion. Ce qu'ils apprennent sert à tous les autres.Your agents get these rules when they connect. What one learns, the others reuse.

  1. Rappeler d'abordRecall first

    Sur une erreur, avant le web, ou avant de répondre sur toi : memory_recall.On an error, before the web, or before answering about you: memory_recall.

  2. Garder ce qui est vérifiéKeep what is verified

    Un correctif, une réponse avec sa source, un fait sur toi ou tes proches : memory_save.A fix, an answer with its source, a fact about you or people you know: memory_save.

  3. Dire si ça a marchéSay if it worked

    Les bonnes entrées remontent, les fausses sont à revérifier puis retirées : memory_feedback.Good entries rise, wrong ones go to recheck then retire: memory_feedback.

03 · dans le binairein the binary

Tout ce qu'il faut, rien à héberger.Everything you need, nothing to host.

Un seul exécutable pour macOS et Linux : le démon, le moteur, le Studio et la CLI.A single executable for macOS and Linux: the daemon, the engine, the Studio and the CLI.

Studio

Vois ce que tes agents demandent, teste une requête, comprends pourquoi un résultat sort et corrige la mémoire.See what your agents ask, test a query, understand why a result comes up and fix the memory.

Historique et sourcesHistory and sources

Chaque entrée garde sa source, ses versions et ses révisions. Un fait qui change remplace l'ancien sans l'effacer.Every entry keeps its source, versions and revisions. A fact that changes replaces the old one without erasing it.

Secrets masquésSecrets masked

Clés d'API, jetons et mots de passe sont masqués avant l'écriture. Mémoire et documents restent des données, jamais des ordres.API keys, tokens and passwords are masked before writing. Memory and documents stay data, never instructions.

loragctl

Indexer, chercher, rappeler et enregistrer depuis le terminal ou un script. Un log d'erreur se passe tel quel sur l'entrée standard.Index, search, recall and save from the terminal or a script. An error log can be piped in as is.

API REST

Tout ce que fait le Studio passe par /api/v1 : recherche, mémoire, statistiques, export en JSON Lines.Everything the Studio does goes through /api/v1: search, memory, stats, JSON Lines export.

Pas que pour le codeNot only for code

Un assistant vocal ou un agent de support ont le même besoin : ne pas redemander ce qu'on leur a déjà dit.A voice assistant or a support agent need the same thing: not to ask again what they were already told.

04 · intégrationsintegrations

Branche n'importe quel client MCP.Plug in any MCP client.

Lorag sert MCP en HTTP sur localhost:8080/mcp. Le Studio donne la configuration de chaque client et la teste.Lorag serves MCP over HTTP on localhost:8080/mcp. The Studio gives each client's configuration and tests it.
